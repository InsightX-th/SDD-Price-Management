# SoundDD Stock & Price

จัดการราคาปกติ ราคาโปร และสถานะสต็อกของ WooCommerce ผ่านหน้าผู้ดูแลระบบเดียว พร้อมตั้งโปรชั่วคราว ดูประวัติการแก้ไข และตรวจสอบรายการที่มีปัญหา

> **รุ่น 0.5.21 เป็นรุ่นทดสอบสำหรับ Local เท่านั้น** ใช้กับเว็บไซต์ทดสอบที่ติดตั้งข้อมูลสำรองของร้าน ห้ามนำขึ้น Production ในตอนนี้

[ดู Release และดาวน์โหลด ZIP](https://github.com/InsightX-th/SDD-Price-Management/releases/tag/v0.5.21)

## ปลั๊กอินนี้ช่วยอะไรได้บ้าง

- ค้นหาสินค้าด้วยชื่อ, SKU, ID หรือแบรนด์ และกรองตามสต็อก สถานะโปร หรือบทความโปรโมชัน
- แก้ราคาปกติ ราคาโปร และสถานะสต็อกของสินค้าที่รองรับ โดยตรวจสอบและยืนยันก่อนบันทึก
- ตั้งโปรชั่วคราวล่วงหน้าหรือเริ่มทันที พร้อมดูผลราคาก่อนยืนยัน
- ดูรายการที่แก้ไขล่าสุด ประวัติโปร และผู้ดำเนินการ
- ตรวจสอบบันทึกเหตุการณ์ทางเทคนิคและดาวน์โหลดเป็น CSV เมื่อมีสิทธิ์

## ข้อกำหนด

- WordPress 6.8 ขึ้นไป
- PHP 8.2 ขึ้นไป
- WooCommerce 10.0 ขึ้นไป
- แนะนำให้ทดสอบบน Local ที่ใช้สำเนาฐานข้อมูลและไฟล์จาก backup

## ติดตั้งและเริ่มใช้งานใน Local

1. ตรวจว่า Local เป็นเว็บไซต์ทดสอบจาก backup แล้วสำรองไฟล์และฐานข้อมูลของ Local ไว้อีกชุด
2. ดาวน์โหลด `sdd-stock-price-0.5.21-local-test.zip` จากหน้า Release
3. ใน WordPress ไปที่ **ปลั๊กอิน → เพิ่มปลั๊กอินใหม่ → อัปโหลดปลั๊กอิน** เลือก ZIP แล้วติดตั้งและเปิดใช้งาน
4. เปิดเมนู **สต็อก & ราคา → ตั้งค่า** แล้วเลือกแท็กที่ใช้เป็นแบรนด์ ปุ่มเลือกทั้งหมดเลือกเฉพาะรายการที่แสดงอยู่หลังการค้นหา
5. ตรวจความพร้อมและยืนยันว่าได้สำรองข้อมูลแล้ว ก่อนกด **เปิดให้แก้ไขสินค้า**
6. ค้นหาสินค้าทดสอบและตรวจผลในหน้าสินค้า WooCommerce หลังบันทึก

ปลั๊กอินไม่ได้ย้ายหรือลบแท็กแบรนด์ การเลือกแท็กใช้สำหรับค้นหาและกรองสินค้าเท่านั้น

## แก้ราคาและสต็อก

ค้นหาสินค้าแล้วเลือกช่องราคาหรือสต็อกที่ต้องการแก้ ระบบจะแสดงค่าก่อนและหลังและขอให้ยืนยันก่อนบันทึก ราคาใช้จำนวนเต็มบาท ไม่มีทศนิยม ส่วนตัวเลขบนหน้าจอจัดรูปแบบให้อ่านง่าย เช่น `12,900`

การแก้ไขสต็อกเปลี่ยนเฉพาะสถานะ เช่น **มีสินค้า**, **สินค้าหมด** หรือ **สินค้าสั่งจอง** ไม่ได้เปลี่ยนจำนวนสินค้า การตั้งค่าจัดการจำนวน หรือการอนุญาตให้สั่งจอง

สินค้าตัวแปรแสดงราคาและสต็อกรวมที่แถวสินค้าหลัก กด **ดูตัวเลือก** เพื่อแก้แต่ละตัวเลือก สินค้าชนิดอื่นที่ยังไม่รองรับจะแสดงเหตุผลและเปิดให้อ่านอย่างเดียว

## ตั้งโปรชั่วคราว

1. กด **จัดการโปร** ที่สินค้า
2. กรอกราคาและวันเวลาเริ่ม/สิ้นสุดตามเขตเวลาของ WordPress
3. ตรวจสรุปราคาอ้างอิง ราคาช่วงโปร และราคาหลังจบโปร
4. เลือกช่องตัวเลือกคืนราคาโปรเดิม หากต้องการใช้ราคาโปรเดิมต่อแม้วันสิ้นสุดเดิมผ่านไปแล้ว
5. กด **ยืนยันตั้งโปรชั่วคราว**

ถ้ามีราคาโปรเดิม ระบบใช้ราคานั้นเป็นราคาอ้างอิงก่อนโปรชั่วคราว หากไม่มีราคาโปรเดิม จะใช้ราคาปกติ เมื่อโปรชั่วคราวจบ ระบบคืนราคาและตารางเดิมตามวันที่จริง โดยปกติราคาโปรเดิมที่หมดอายุแล้วจะกลับไปใช้ราคาปกติ

ระบบอัตโนมัติของ WordPress ต้องทำงานเพื่อเริ่มและคืนราคาให้ตรงเวลา หากมีการแก้ราคาหรือวันโปรระหว่างโปรชั่วคราว ระบบจะหยุดคืนราคาอัตโนมัติและทำเครื่องหมาย **ต้องตรวจสอบ** เพื่อป้องกันการเขียนทับการแก้ไขใหม่

## ประวัติและบันทึกเหตุการณ์

แท็บ **แก้ไขล่าสุด** แสดงรายการที่เปลี่ยนราคาผ่านปลั๊กอินนี้ รวมการเริ่มและคืนโปรชั่วคราว ประวัติแสดงชื่อบัญชีและอีเมลของผู้ดำเนินการตามข้อมูล WordPress ผู้ที่มีสิทธิ์ดูบันทึกเหตุการณ์สามารถกรองรายการและดาวน์โหลด CSV ได้

หากคำสั่งบันทึกไม่แน่ชัด ให้ใช้ปุ่มตรวจผลของรายการเดิมก่อน อย่าส่งคำสั่งซ้ำ เพราะระบบอาจกำลังตรวจผลจากเซิร์ฟเวอร์อยู่
