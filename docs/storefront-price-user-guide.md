# คู่มืออัปเดตราคาหน้าร้าน SoundDD

ใช้คู่มือนี้กับรุ่นที่มีเมนู **การอัปเดตราคาหน้าร้าน** ในปลั๊กอิน SoundDD Stock & Price หากยังไม่เห็นเมนู ให้ผู้ดูแลเว็บไซต์ตรวจรุ่นปลั๊กอินและสิทธิ์ของบัญชี

## สำหรับทีมที่แก้ราคา

1. เปิด **สต็อก & ราคา** ใน WordPress แล้วค้นหาด้วยชื่อหรือ SKU
2. เลือกสินค้าหรือตัวเลือกที่ต้องการ แก้ราคาปกติหรือราคาโปร แล้วตรวจราคาและรายการสินค้าก่อนยืนยัน หากเป็นโปรชั่วคราว ให้ตรวจวันเริ่ม วันสิ้นสุด และราคาที่คาดว่าจะกลับไปใช้หลังหมดโปร
3. เมื่อปลั๊กอินยืนยันว่าบันทึกสำเร็จ ราคาใน WooCommerce ถูกบันทึกแล้ว ถ้าเปิด Auto Purge ระบบจะส่งงานล้างแคชหลังบันทึก และเก็บงานเริ่มกับคืนราคาโปรเมื่อเกิดการเปลี่ยนราคาจริง
4. เปิดหน้าสินค้าและหน้าที่แสดงสินค้านั้นจากหน้าต่างไม่ระบุตัวตน โดยเฉพาะหน้าหมวดหมู่หรือหน้าโปรที่ลูกค้าใช้งาน หากเป็นสินค้าที่มีตัวเลือก ให้เลือกตัวเลือกเดียวกับที่แก้ราคา

| สถานะในปลั๊กอิน | สิ่งที่ควรทำ |
|---|---|
| รอหรือกำลังอัปเดต | รอให้คิวทำงาน แล้วรีเฟรชสถานะ |
| ทดลอง | ระบบเดินคิวโดยไม่ส่งคำขอไป Cloudflare หน้าร้านอาจยังแสดงราคาที่อยู่ในแคช |
| Cloudflare รับคำขอแล้ว | ตรวจราคาบนหน้าร้านจริง สถานะนี้ยืนยันการตอบรับจาก API |
| ต้องตรวจสอบ | แจ้งผู้ดูแลพร้อม SKU และ URL ของหน้าที่แสดงราคาเก่า ผู้ดูแลตรวจสาเหตุแล้วลองส่งงานล้างแคชอีกครั้งได้ |
| โปรต้องตรวจสอบหรือเลยเวลาคืน | เช็กราคาปัจจุบันและประวัติโปรก่อนแก้เพิ่ม การคืนราคาอาจหยุดเมื่อระบบพบว่าราคาถูกแก้ระหว่างโปร |

ถ้าราคาบันทึกแล้วแต่หน้าร้านยังเก่า ให้แจ้งผู้ดูแลพร้อมหน้าที่พบและเวลาที่ตรวจ การกดลองอัปเดตหน้าร้านใหม่จะส่งเฉพาะงานล้างแคช

## ตั้งค่าครั้งแรกสำหรับผู้ดูแลเว็บไซต์

1. เปิด **ตั้งค่า → การอัปเดตราคาหน้าร้าน → การเชื่อมต่อ Cloudflare**
2. ใส่ Zone ID ของเว็บไซต์และ API Token ที่มีสิทธิ์ **Cache Purge** เฉพาะโดเมนนั้น แล้วกด **ตรวจการเชื่อมต่อและบันทึก** การตรวจนี้ส่งคำขอล้าง URL ทดสอบเพื่อเช็กสิทธิ์
3. เปิด **อัปเดตราคาหน้าร้านอัตโนมัติ** คงเครื่องหมาย **ทดลองระบบโดยยังไม่อัปเดตเว็บไซต์จริง** ไว้ แล้วกดบันทึก
4. ระบบรวมหน้าสินค้า หน้าร้าน หน้าแรก หมวดหมู่ และหน้าที่ตรวจพบว่าแทรกสินค้า ดูรายการที่ตรวจพบได้ในหน้าตั้งค่า ใช้ **เพิ่มหน้าพิเศษด้วยตนเอง** เมื่อหน้าสาธารณะบนโดเมนเดียวกันแสดงราคาจาก WooCommerce แต่ระบบตรวจไม่พบ ใส่หนึ่ง URL ต่อบรรทัด ราคาที่พิมพ์ไว้ในข้อความหรือฝังในรูปต้องแก้จากต้นทาง

Auto Purge ใน SoundDD ครอบคลุมการแก้ผ่าน SoundDD การแก้ผ่าน WooCommerce โดยตรงและระบบนำเข้ายังขึ้นกับการตั้งค่าแคชเดิมของเว็บไซต์

## เริ่มใช้งานบน Prod เมื่อไม่มี Staging

1. เก็บ ZIP รุ่นเดิมและสำรองฐานข้อมูลก่อนติดตั้ง ใช้ผลทดสอบ Local ตรวจการบันทึกแบบรายการเดียว แบบ Bulk และการเริ่มกับคืนราคาโปร
2. คงโหมดทดลองไว้บน Prod แล้วใช้การเปลี่ยนราคาหนึ่งรายการที่ร้านอนุมัติอยู่แล้ว ตรวจว่าราคาใน WooCommerce ถูกต้องและคิวขึ้นสถานะทดลอง
3. ปิดโหมดทดลองและบันทึก ก่อนการเปลี่ยนราคาครั้งถัดไปที่ร้านวางแผนไว้ ตรวจว่าคิวจบ แล้วเปิดหน้าสินค้าและหน้าหมวดหมู่หรือหน้าโปรแบบไม่ระบุตัวตนทั้งมือถือและเดสก์ท็อป
4. เริ่ม Bulk ด้วยชุดเล็ก ตรวจว่าคิวไม่ค้างและราคาถูกต้องก่อนเพิ่มจำนวนสินค้า ถ้าพบปัญหา ให้พักด้วยสวิตช์ **อัปเดตราคาหน้าร้านอัตโนมัติ** ส่วนสวิตช์ **หยุดการแก้ไขชั่วคราว** มีผลกับการบันทึกและการเริ่มหรือคืนราคาโปรทั้งร้าน

สำหรับผู้ดูแลที่ต้องตรวจการตั้งค่าและคิวเพิ่มเติม ดู [คู่มือ Cloudflare Auto Purge](cloudflare-auto-purge.md)
