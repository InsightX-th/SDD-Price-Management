## สำหรับผู้ดูแลร้าน

- **แก้ราคาหลายรายการ** กรอกแยกแต่ละสินค้า หรือใช้สูตรเดียวทั้งชุด ตรวจราคาเดิม ราคาใหม่ และส่วนต่างก่อนบันทึก
- **โปรชั่วคราว** กำหนดช่วงเวลาร่วมกันสำหรับหลายสินค้า หรือเปลี่ยนราคาของโปรที่มีอยู่โดยใช้แผนเวลาเดิม
- **สินค้าชุดและสต็อก** แก้ราคาฐานและตั้งโปรให้สินค้าชุดจาก WooCommerce Product Bundles ได้ เห็นจำนวนคงเหลือเมื่อ WooCommerce มีข้อมูล
- **ติดตามงาน** ค้นหาตัวเลือกด้วย SKU ใช้ตัวกรองปฏิทิน ตรวจผลคำสั่งโปรที่ค้าง และติดตามคิวแคชตามรายการ

## อัปเกรดจาก 0.5.31

ติดตั้งบน WordPress 6.8+, PHP 8.2+ และ WooCommerce 10.0+ สำรองไฟล์และฐานข้อมูลก่อนอัปเกรด แล้วอัปเดตจากหน้า **ปลั๊กอิน** หรืออัปโหลด `sdd-stock-price-0.6.0.zip` ทับรุ่นเดิม หลังติดตั้งตรวจเวอร์ชัน เปิดหน้าสินค้า และตรวจโปรที่กำลังใช้หรือรอเริ่มก่อนแก้ราคา โปรที่ตั้งไว้ยังใช้ข้อมูลเดิมและอาศัย WordPress Cron เพื่อเริ่มหรือคืนราคา

หากร้านเปิดการอัปเดตราคาหน้าร้านผ่าน Cloudflare ให้ตรวจการเชื่อมต่อและคิวหลังอัปเกรด คิวที่รอส่งดูได้ในหน้า **ตั้งค่า** [คู่มือการอัปเดตราคาหน้าร้าน](../storefront-price-user-guide.md)

## ผลการตรวจรุ่นนี้

- ผ่าน 76 เทสต์ JavaScript และตรวจ syntax บน PHP 8.2
- ติดตั้งและอัปเกรด ZIP จาก 0.5.31 ใน WordPress แยก โปรที่เริ่มไว้ก่อนอัปเกรดคืนราคาเดิมได้
- ทดสอบการตั้งและคืนโปรสินค้าชุด การกู้ผลเมื่อฐานข้อมูลหลุด การพักเขียนราคาพร้อมเปลี่ยนการตั้งค่า และงานสำรองเมื่อไม่มี tick ของโปร
- ตรวจหน้าจอบนเดสก์ท็อป 1280 px และมือถือ 390/320 px รวมการเลือกสินค้า การแสดงสต็อก และการกรอกราคาโปร
- ทดสอบ Cloudflare และตัวตรวจรุ่น WordPress ด้วย HTTP จำลอง การทดสอบชุดนี้ทำใน Local โดยไม่ส่งคำขอ Cloudflare ไปยัง Production
