# Validation: 0.5.29

วันที่ตรวจ: 2026-11-02

## ขอบเขต

ปรับ UX/UI ของหน้าจัดการสินค้า ภาพรวมงาน และปฏิทิน พร้อมการแสดงแผน/ผลคืนราคา เพิ่มข้อมูลอ่านใน API รายการโปร โดยไม่เปลี่ยนขั้นตอนเขียนราคาและคืนราคาของระบบเดิม

## ผลตรวจ

- JavaScript syntax และ PHP lint ของไฟล์ runtime/tests ผ่าน
- Client/session: 12 กรณีผ่าน ครอบคลุม nonce, session หมดอายุ, ผลบันทึกไม่แน่ชัด และการไม่ส่งคำสั่งเดิมซ้ำโดยพลการ
- UI/model: 12 กรณีผ่าน ครอบคลุมแถบโปรข้ามเดือน/สัปดาห์ รายการซ้อน แผนคืนโปรที่หมดอายุ สถานะสำเร็จ/ติดปัญหา แบบร่าง URL และข้อความยืนยัน
- Local WordPress integration: 19 กรณีผ่าน (dashboard 8, calendar/alerts 4, missed promotion 2, return status 5) ข้อมูล fixture rollback หลังจบ
- ทดลอง UI จาก component จริงด้วยข้อมูลตัวอย่างบน Desktop และมือถือ: เปิดตัวเลือกย่อยจากแจ้งเตือน, กลับไปช่องค้างพร้อมตัวเลขที่พิมพ์, ยืนยันการปิดรายการโดยคงราคา, Back และรีโหลดแล้วจำเดือนเดิม
- ตรวจไฟล์ JavaScript/CSS ที่ Local ส่งออกมาตรงกับไฟล์ที่ทดสอบ

## ข้อจำกัด

การตรวจภาพและเส้นทาง UI ใช้ข้อมูลตัวอย่าง ส่วน integration ใช้ฐานข้อมูล Local ไม่ได้ทดสอบอัปเดตติดตั้งหรือซื้อสินค้า/ชำระเงินจริงบน production การคืนราคาตรงเวลายังต้องมีระบบเรียกงานอัตโนมัติของเว็บไซต์

บรรจุ ZIP เฉพาะไฟล์ runtime, README และ CHANGELOG ไม่รวม test, Git metadata หรือข้อมูล Local
