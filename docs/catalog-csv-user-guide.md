# คู่มือหน้าสินค้า แก้ราคาหลายรายการ และนำเข้าราคาโปร

## ดูสินค้าและราคา

ค้นด้วยชื่อ รุ่น SKU แบรนด์ หรือ ID และใช้ตัวกรองประกอบได้ แท็บ **โปรชั่วคราวกำลังใช้**, **โปรชั่วคราวใกล้หมด** และ **โปรชั่วคราวรอเริ่ม** แสดงเฉพาะโปรชั่วคราวของปลั๊กอิน ไม่รวมโปรถาวร ตาราง WooCommerce หรือรายการต้องตรวจสอบ ส่วนโปรประเภทอื่นยังค้นได้จากสินค้าทั้งหมดและตัวกรองสถานะโปร

เมื่อสลับแท็บ ระบบเก็บคำค้น แบรนด์ สต็อก และตัวกรองอื่นไว้ ล้างเฉพาะสถานะโปร จำนวนบนแท็บนับสินค้าแม่หนึ่งครั้ง แม้มีหลายตัวเลือกที่ตรงเงื่อนไข

**ราคาโปรที่บันทึก** คือค่าที่ตั้งไว้ หากต่างจากราคาที่กำลังใช้ จะมีข้อความ **ใช้ในระบบตอนนี้ … บาท** โปรรอเริ่มแสดงราคาใหม่คู่กับวันเริ่ม สินค้าที่มีหลายตัวเลือกแสดงช่วงราคา เปิดตัวเลือกก่อนแก้รายสินค้า ดูแผงจัดการโปรตามลำดับ **ปัจจุบัน → ระหว่างโปร → หลังจบ**

ราคาในระบบไม่ยืนยันว่าผู้ซื้อทุกคนเห็นราคาเดียวกันทันที เพราะหน้าร้านอาจยังติดแคช วันเวลาแสดงผลเป็นปี พ.ศ. ตามเวลาเว็บไซต์ ส่วนช่องกรอกและ CSV ใช้ปี ค.ศ.

## อ่านป้ายสต็อกและแก้สินค้าชุด

- ป้าย **คงเหลือ** แสดงจำนวนที่ WooCommerce คำนวณได้ ใช้หน่วย **ชุด** สำหรับ Bundle และ **ชิ้น** สำหรับสินค้าอื่น ถ้าตัวเลือกใช้จำนวนจากสินค้าแม่จะขึ้น **สต๊อกร่วม**
- สินค้าชุดที่ใช้ WooCommerce Product Bundles แก้ราคาปกติ ราคาโปร และโปรชั่วคราวจากแถวสินค้าได้ หากส่วนประกอบคิดราคาแยก ให้ดูคำอธิบายราคาฐานก่อนยืนยัน

## แก้ราคาและโปรหลายรายการ

ติ๊กเลือกสินค้าทั่วไปหรือตัวเลือกสินค้า แล้วกด **แก้ราคาหลายรายการ** ระบบจะโหลดราคาและโปรล่าสุดของรายการที่เลือกก่อนเปิดหน้าแก้ไข

| วิธี | ใช้เมื่อ |
| --- | --- |
| **กรอกราคาแยกแต่ละสินค้า** | ระบุช่องราคาและราคาใหม่เองในแต่ละแถว เว้นช่องว่างสำหรับสินค้าที่ไม่ต้องการแก้ |
| **ใช้สูตรเดียวทั้งชุด** | เพิ่มหรือลดเป็นบาทหรือเปอร์เซ็นต์จากช่องราคาอ้างอิงที่เลือก |
| **ตั้งโปรชั่วคราว** | กำหนดให้เริ่มหลังบันทึกหรือเลือกเวลาเริ่ม กำหนดวันจบร่วมกัน แล้วกรอกราคาต่อสินค้า สูงสุด 100 สินค้าต่อชุด |
| **แก้โปรชั่วคราว** | เปลี่ยนราคาของโปรที่ใช้อยู่หรือรอเริ่ม โดยใช้เวลาและแผนคืนราคาเดิม |

ดูราคาเดิม ราคาใหม่ ส่วนต่าง หรือราคาหลังจบตามแผน กดปุ่มตรวจของโหมดที่เลือก แล้วจึงยืนยันและอ่านผลรายสินค้า หากขึ้น **ต้องตรวจสอบ** ให้เปิด **จัดการโปร** ของสินค้านั้น กด **ตรวจผลคำสั่งโปร** และดูประวัติก่อนเลือกคงราคาปัจจุบันหรือเตรียมตั้งโปรใหม่

## นำเข้าไฟล์

1. เปิด **นำเข้าโปรจาก CSV** จากหน้าสินค้าหรือปฏิทิน เลือก **โปรชั่วคราว** หรือ **ราคาโปรถาวร**
2. ดาวน์โหลดไฟล์ตัวอย่างให้ตรงประเภท ใช้ UTF-8 ไม่เกิน 100 รายการและ 256 KB
3. ระบุชื่อเต็มหรือรหัสรุ่นใน `product_name` และราคาเต็มบาทที่มากกว่า 0 ใน `sale_price` โปรชั่วคราวเพิ่ม `starts_at,ends_at` รูปแบบ `2026-11-20 09:00` ตามเวลาเว็บไซต์ โดยเริ่มในอนาคตและจบหลังเริ่ม
4. เลือกไฟล์ ตรวจสินค้าที่ระบบจับจากรุ่น ถ้าพบหลายรายการหรือไม่พบ ให้ค้นหาและเลือกสินค้าเอง ตรวจชื่อเต็มและตัวเลือกให้ตรง
5. เปรียบเทียบราคาปัจจุบันกับราคาใหม่ แก้ราคาและวันเวลาในตารางได้ แล้วกด **ตรวจแถวนี้** แถวที่ผ่านแล้วก็แก้ได้ การตรวจยังไม่เปลี่ยนราคาสินค้า
6. เมื่อทุกแถวผ่าน ไม่มีสินค้าซ้ำ และไม่มีค่าที่ยังไม่ตรวจ กด **ยืนยันตั้งโปร … รายการ** หรือ **ยืนยันเปลี่ยนราคา … รายการ** แล้วอ่าน **ผลการนำเข้า** โดยเฉพาะรายการที่มีปัญหา

โปรถาวรใช้ราคาใหม่ทันทีและล้างวันโปรเดิม อาจมีบางรายการบันทึกไม่ได้ จึงต้องอ่านผลรายแถว โปรชั่วคราวใช้กลไกบันทึกทั้งชุดเดิมและเปลี่ยนราคาตามเวลาเริ่ม

## พักงาน กลับมาทำต่อ และหมดอายุ

- **กลับไปจัดการสินค้า** เก็บเฉพาะข้อมูลที่ตรวจแล้วบนเซิร์ฟเวอร์จนครบ 15 นาที ไม่เก็บค่าที่กำลังพิมพ์ หากมีค่าค้าง ระบบให้เลือกกลับไปแก้ต่อหรือออกโดยไม่ใช้ค่านั้น
- เปิดเมนูนำเข้าในแท็บเบราว์เซอร์เดิมอีกครั้ง ระบบเรียกตรวจสถานะให้อัตโนมัติ ไม่สั่งบันทึกต่อเอง ถ้าบันทึกค้างอยู่ ให้ตรวจจำนวนที่ทำแล้วและกด **ทำรายการที่เหลือต่อ**
- เครือข่ายขัดข้อง: ใช้ **ตรวจสถานะชุดเดิม** เพื่ออ่านผลเดิม หลีกเลี่ยงอัปโหลดชุดใหม่ก่อนทราบผล
- ใกล้ปุ่มมีเวลา **เก็บชุดนี้ไว้ถึง … น.** อ้างอิงเซิร์ฟเวอร์ แก้แถวแล้วไม่ต่ออายุ เหลือไม่เกิน 5 นาทีจะเตือนหนึ่งครั้ง
- ครบเวลา: ระบบปิดการยืนยันและตรวจสถานะก่อน เพราะคำสั่งอาจเสร็จแล้ว หากหมดอายุจริง ตารางที่เปิดอยู่ยังอ่านหรือคัดลอกได้ แต่ต้องเลือกไฟล์ใหม่เพื่อดำเนินงานต่อ หากกลับมาหลังหมดอายุและไม่มีตารางอยู่แล้ว ต้องอัปโหลดใหม่
- ถ้าข้อมูลสินค้าเปลี่ยนระหว่างแก้ ระบบเก็บข้อความที่พิมพ์ไว้และขอให้ตรวจข้อมูลล่าสุดก่อนใช้ ไม่ย้ายค่าที่พิมพ์ไปใช้กับสินค้าอีกตัวเอง

## ยกเลิกชุดตรวจ

**ยกเลิกชุดนี้** ล้างชุดที่ยังไม่เริ่มบันทึกและกลับไปเลือกไฟล์ ถ้าเคยแก้ข้อมูลหรือเลือกสินค้า ระบบจะถามก่อนล้าง ชุดที่เริ่มบันทึกแล้วจะยกเลิกผ่านปุ่มนี้ไม่ได้ ต้องอ่านผลชุดเดิม การยกเลิกชุดตรวจไม่ใช่การย้อนคืนราคาที่บันทึกไปแล้ว

## ใช้คีย์บอร์ดและจอเล็ก

ใช้ Tab เลื่อนไปยังปุ่มและช่องกรอก มีกรอบโฟกัสชัดเจน ตารางเลื่อนแนวนอนได้เพื่อรักษาชื่อรุ่นและราคาครบ เมื่อเปิดชุดเดิมจะโฟกัสหัวข้อตรวจรายการ ตรวจแถวไม่ผ่านจะกลับไปช่องผิด เมื่อยกเลิกจะกลับหัวข้อเลือกไฟล์


## อ่านผลเปรียบเทียบก่อนยืนยัน

เหนือรายการมีสรุปราคาลดลง เพิ่มขึ้น เท่าเดิม หรือยังเทียบไม่ได้ โดยอ้างอิง **ผลตรวจล่าสุด** ในแต่ละแถวดูส่วนต่างบาทและเปอร์เซ็นต์ประกอบได้ ถ้าราคาเดิมเป็นศูนย์ ระบบไม่คำนวณเปอร์เซ็นต์ เมื่อแก้ราคาในช่องแล้วต้องกด **ตรวจแถวนี้** เพื่อให้สรุปรวมใช้ค่าที่ตรวจใหม่

ราคาเท่าเดิมยังอาจมีผลกับตารางโปร สำหรับโปรถาวร ให้ดูข้อความจำนวนรายการที่จะล้างวันโปรเดิมด้วย ระบบไม่ตัดรายการราคาเท่าเดิมออกเอง ราคาสินค้าจะเปลี่ยนหลังยืนยันทั้งชุดเท่านั้น

เมื่อกดแก้แถว โฟกัสจะไปช่องกรอก เมื่อยกเลิกการแก้หรือตรวจผ่านจะกลับปุ่มแก้แถวเดิม ตรวจไม่ผ่านจะไปช่องที่ต้องแก้ บนมือถือเลื่อนแท็บแนวนอนเพื่อเลือกสถานะเพิ่มเติมได้ หรือใช้ปุ่มลูกศรเมื่อโฟกัสอยู่บนแท็บ

## ตัวกรองแบรนด์และสถานะตั้งค่า

หากยังไม่ตั้งค่าข้อมูลแบรนด์ จะเห็นคำอธิบายแทนช่องกรอง ผู้ดูแลที่มีสิทธิ์กด **ตั้งค่าตัวกรองแบรนด์** เพื่อไปส่วนที่เกี่ยวข้องได้ ผู้ใช้สิทธิ์อื่นให้ติดต่อผู้ดูแล ระหว่างโหลดระบบแสดงกำลังอ่านข้อมูล หากอ่านไม่ได้ให้ลองใหม่ สถานะกำลังโหลดไม่ใช่การปิดการแก้ไข
